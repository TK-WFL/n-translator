# Contributing / 参加のしかた

## 日本語

- **Issue は誰でも歓迎します。** 不具合の報告・使い方の質問・機能の提案は [Issues](https://github.com/TK-WFL/n-translator/issues) からどうぞ（テンプレートがあります）
- **Pull Request はメンテナー（コラボレーター）だけが作成できる設定にしています。** コードの変更を提案したいときは、Issue に内容を書いてください
- MIT ライセンスなので、フォークして自分用に改造するのは自由です
- **Issue に API キー・`ACCESS_KEY`・Notion のトークン・個人情報を書かないでください。** ログやスクリーンショットを貼るときは、`workers.dev` の URL や Notion の内容も含め、必要に応じて隠してください。うっかり貼ってしまったら、すぐにキーを作り直してください
- セキュリティ上の問題は Issue ではなく [SECURITY.md](SECURITY.md) の方法で非公開で知らせてください

## English

- **Issues are welcome from everyone** — bug reports, questions and feature ideas via [Issues](https://github.com/TK-WFL/n-translator/issues) (templates provided)
- **Pull requests can only be opened by maintainers (collaborators).** To propose a code change, describe it in an issue
- Forking and modifying it for your own use is welcome under the MIT license
- **Never post API keys, your `ACCESS_KEY`, Notion tokens or personal information in issues.** Redact logs and screenshots (including your `workers.dev` URL and Notion content) as needed. If you posted a key by mistake, rotate it immediately
- Report security problems privately as described in [SECURITY.md](SECURITY.md), not in public issues
